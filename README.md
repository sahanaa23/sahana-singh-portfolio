## Run locally
No build tools or package installation are required. Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment
GitHub Pages deployment is configured through the workflow in `.github/workflows/deploy.yml`.
